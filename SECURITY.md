# Security Policy

This repository is a research implementation of a published cryptanalysis. BCIEA is not considered secure, and no part of this repository should be used as a production cryptographic primitive.

For a reproducibility defect, incorrect paper attribution, or a flaw in the maintained reference model, open a GitHub issue with a minimal synthetic reproducer. Do not include private keys, private images, proprietary ciphertexts, or information obtained from an unauthorized target.

Reports about unrelated applications that merely use this repository should be directed to the owner of those applications.
